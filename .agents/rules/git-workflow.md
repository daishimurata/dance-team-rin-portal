# Git ＆ デプロイ運用ルール（ローカル検証・Vercelビルド最適化）

本プロジェクト（`dance-team-rin-portal`）の開発・修正作業では、以下の運用フローを厳守すること。

## 開発・デプロイルール
1. **作業開始前（最新化）**:
   - 編集を開始する前に、必ず `git pull origin main` を実行して最新コードを取得・同期する。

2. **作業中（ローカル検証）**:
   - 細かい修正やUI・動作の試行錯誤はすべてローカル環境（`npm run dev`）上で確認する。
   - 途中の微修正段階ではリモートへのプッシュを行わない（Vercelの不要な自動ビルド発生とコスト・リソース浪費を防ぐため）。

3. **作業完了時（確定プッシュ）**:
   - ローカルでの動作確認が完了し、「これで本番反映して決定」となった段階で、まとめてコミット（`git commit`）し、リモートへプッシュ（`git push origin main`）してVercelに反映させる。
